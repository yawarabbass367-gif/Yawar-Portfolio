# Artemis Portfolio Clone

A Next.js clone of the [Artemis Framer portfolio template](https://artemis1.framer.website/) with page transitions, scroll reveals, marquees, custom cursor, and FAQ motion.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Home (hero, works, marquee, about, testimonials, brands, FAQ, contact)
- `/works` — All projects
- `/works/[slug]` — Project detail
- `/playground` — Experimental gallery

## Stack

Next.js 15 · React 19 · Tailwind CSS 4 · Framer Motion · Google Fonts (DM Sans, Libre Baskerville, Fragment Mono)
